# The trimmed LLVM 22 the Linux package ships as tools/llvm (docs/Releasing.md, "Linux package"), taken from
# the distribution's install (Ubuntu 26.04: clang-22, lld-22, lldb-22, libclang-22-dev, 1:22.1.2-1ubuntu1).
# One entry per line, relative to the LLVM root (/usr/lib/llvm-22): a file, or a folder ending in "/" (copied
# whole). "!" excludes a file or folder under an included folder. "[debug]" marks what only the debugger needs
# (package-linux.sh --no-debugger leaves those out). "a -> b" makes a as a symbolic link to b (same folder).
# Symbolic links among the entries are copied as the files they point to. An absolute path is a library of the
# system copied into lib/ under its own name (a dependency the LLVM libraries need that a desktop system may
# lack). Every binary here has RUNPATH $ORIGIN/../lib, so bin/ and lib/ find each other wherever the folder is.

# The compiler driver and the linker (clang -fuse-ld=lld runs bin/ld.lld).
bin/clang
bin/lld
bin/ld.lld -> lld
# Target defaults for the programs the back end links: compiler-rt start-up files and builtins, no libgcc
# (packaging/x86_64-pc-linux-gnu.cfg, copied into bin/ by the script; so no GCC needs to be installed).

# The LLVM libraries the tools load, and libclang for the C import (LibClang.bf: lib/libclang.so of the root).
lib/libLLVM.so.22.1
lib/libclang-cpp.so.22.1
lib/libclang.so

# The debugger: lldb-dap, the lldb library, and lldb-server (lldb on Linux launches and controls the program
# through "lldb-server gdbserver"; lldb-argdumper expands launch arguments).
bin/lldb-dap [debug]
bin/lldb-server [debug]
# (Debian's liblldb runs it as lldb-server-<version>: the script keeps the versioned links of the source.)
bin/lldb-argdumper [debug]
lib/liblldb-22.so.1 [debug]

# clang's builtin headers and the compiler runtime for x86-64 Linux (builtins and crtbegin / crtend).
lib/clang/22/include/
lib/clang/22/lib/linux/libclang_rt.builtins-x86_64.a
lib/clang/22/lib/linux/clang_rt.crtbegin-x86_64.o
lib/clang/22/lib/linux/clang_rt.crtend-x86_64.o
