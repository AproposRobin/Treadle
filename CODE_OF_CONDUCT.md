# Code of conduct

This project is a place to build a programming language and its tools together. Everyone taking part in its issues,
pull requests, discussions and any other project space is expected to keep it a good place to do that.

## Expected

- Be respectful and patient, including when you disagree. Criticise ideas and code, not people.
- Assume good faith; many contributors are new to the project, to programming or to English.
- Keep discussions on topic and give others room to speak.
- Accept the maintainer's decisions on scope and design, and ask for the reasoning if it is not clear.

## Not accepted

- Harassment, insults, threats, or discriminatory remarks of any kind.
- Sexualised language or imagery, and unwelcome personal attention.
- Publishing someone's private information without their explicit permission.
- Spam, repeated off-topic posts, or deliberately disrupting discussions.

## Reporting

Report conduct problems privately to the maintainer. Until the repository lists a dedicated contact, use GitHub
private reporting on https://github.com/AproposRobin/Treadle (Security tab, "Report a vulnerability") and say that it
is a conduct report. Reports are handled confidentially.

## Enforcement

The maintainer may remove, edit or reject comments, commits, issues and pull requests that break this code, and may
warn, temporarily block or permanently ban a participant. Decisions are made case by case and, where reasonable,
explained to the person concerned.

This code applies in all project spaces and when someone represents the project in public.
